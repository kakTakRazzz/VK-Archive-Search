# VK Archive Search

Локальный поисковик по HTML-архиву VK.

## Запуск

1. Распакуйте архив/папку с этими файлами.
2. Откройте `index.html` в Chrome или Edge.
3. Нажмите «Выбрать папку».
4. Выберите папку `messages` из экспорта VK. Также можно выбрать корень всего VK-архива.
5. Дождитесь индексации.
6. Введите слово или фразу.

## Поддерживаемые файлы

Сканируются HTML-файлы, пути которых заканчиваются на:

- `messages0.html`
- `messages50.html`
- `messages100.html`
- и т. д.

Код понимает кодировку `windows-1251`.

## Контекст

У найденного сообщения есть кнопка «Открыть контекст».
Она показывает заданное количество соседних сообщений из того же диалога.
Число можно выбрать: 1, 2, 3, 5 или 10 сообщений до/после.

## Приватность

Никаких запросов к серверу приложения нет. Файлы читаются браузером локально.
